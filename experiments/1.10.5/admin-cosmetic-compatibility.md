# 1.10.5 item catalogue checks

Build 365075 has 7,024 unique item IDs in the 138 non-drop-table assets under `Gameplay/Backend/Catalogs`. The list in `DauntlessUnbrokenMetagame/src/vendor/item_ids_1105.json` comes from DataTable rows with an `IsStackable` property. Extraction used the installed `Archon_*-WindowsClient.pak` files, repak, and UAssetAPI 1.1.0 with UE 4.26. One spear asset has its `.uasset` and `.uexp` in different paks. `generate-item-ids.py` checks the decoded export count, duplicate kinds and item count before producing the list. IDs are compared without case sensitivity because the native configuration contains mixed-case references to catalog rows.

The old administrator catalogue contains 21 IDs absent from these native tables. In 1.10.5 mode, catalogue search and individual and bulk administrator grants exclude them. Inventory transactions for 1.10.5 accounts also reject additions outside the list, including saves that would create an instance. Existing instances can be saved and removed; stored inventory and historical transaction receipts are retained. This applies to grants that use the shared inventory transaction, including store, Trials and Slayer Link rewards. The separate one-time migration scripts remain responsible for their own imports and preserve old inventory.

This check does not prove that every item works in game, or that no native operation uses an identifier outside the item tables. It does not block old items already present in saved inventory or validate loadouts, account entitlements, game-side drops, quests or crafting definitions. The two initial cosmetic examples were independently checked against the installed `Archon_23-WindowsClient.pak`: both extracted weapon cosmetic `.uasset` and `.uexp` pairs matched the decoded source files byte for byte. No in-game validation was performed.
