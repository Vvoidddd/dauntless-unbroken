# Dauntless Unbroken

Yhteisöpalvelin Dauntless 1.10.5 -pelille.

- [Lataa käynnistin](https://github.com/Vvoidddd/dauntless-unbroken/releases/latest)
- [Ohjeet](https://vvoidddd.github.io/dauntless-unbroken/fi/)
- [English README](README.md)

Käynnistin, tallennettava eteneminen ja tarvittaessa käynnistyvät metsästyspalvelimet. Vanhan Unbroken 1.4.4 -tilin avainta voi käyttää, ja soveltuvat tilit tuodaan 1.10.5-tietokantaan. Version 1.10.5 offline-peli ei ole vielä saatavilla.

AGPL-3.0-only. Alkuperäiset lisenssit ja tekijänoikeustiedot säilytetään [lisenssitiedoissa](UPSTREAM.md).
