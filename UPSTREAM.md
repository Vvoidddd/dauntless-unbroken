# Source and contributor credits

Dauntless Unbroken is an independent community project maintained by
[Vvoidddd](https://github.com/Vvoidddd). Its server and launcher retain the
features of [Dauntless Revived](https://github.com/mixutin/dauntless-revived)
at revision `055702eac78f6a6d98f306f2e407ccfd739f9cbe`, maintained by mixutin,
which builds on [Undaunted](https://github.com/SyST3MDeV/Undaunted) by
Gregory Morford (gwog / SyST3MDeV).

The complete upstream Git history and contributor authorship are preserved.
