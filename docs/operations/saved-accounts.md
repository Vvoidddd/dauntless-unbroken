# Saved launcher accounts

Open **Settings → Account → Saved accounts**. Import each player's existing backup or choose **Add account key…** once. The current account is saved automatically when upgrading. Select **Switch account** beside the other player, or use the account menu at the top of the launcher.

Close the game before switching. Online progress and online playtime belong to the selected server account; the PC's offline save remains separate. Game downloads are shared, so another installation is unnecessary.

Keys stay encrypted in the operating system's launcher storage. A rejected key leaves the current account selected. Saved identities remain bound to their server and certificate. Removing a saved account removes its local sign-in, while retaining server progress and exported backup files.
